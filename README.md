# Loyalty Program ROI Dashboard

## 📊 Project Overview

The **Loyalty Program ROI Dashboard** is an interactive Power BI project designed to analyze customer loyalty performance, revenue trends, and loyalty program costs.

This dashboard helps businesses understand revenue across different loyalty tiers, track monthly revenue, and monitor important business performance indicators.

## 🎯 Project Objectives

- Analyze total revenue generated by customers.
- Understand customer loyalty tier performance.
- Track monthly revenue trends.
- Monitor discounts and reward costs.
- Create an interactive dashboard using Microsoft Power BI.
- Support data-driven business decisions.

## 📌 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

1. **Total Revenue:** Total amount generated from customer orders.
2. **Total Customers:** Count of customer IDs.
3. **Total Transactions:** Count of transaction IDs.
4. **Total Discounts:** Total discount amount provided to customers.
5. **Total Reward Costs:** Total cost associated with customer rewards.
6. **Total Gross Profit:** Gross profit generated from transactions.

## 📈 Dashboard Visualizations

### 1. Revenue by Loyalty Tier
A column chart comparing revenue across four loyalty tiers:

- Bronze
- Silver
- Gold
- Platinum

This visualization helps identify which loyalty tier generates the most revenue.

### 2. Monthly Revenue Trend
A line chart showing monthly revenue changes from January to December.

It helps identify revenue fluctuations and high-performing months.

### 3. Loyalty Tier Slicer
An interactive filter that allows users to analyze dashboard metrics for individual loyalty tiers.

### 4. Purchase Date Slicer
A date-range filter that allows users to analyze performance over a selected period.

## 🔍 Key Insights

The dashboard can be used to investigate:

- Which loyalty tier generates the highest revenue.
- How revenue changes from month to month.
- How much the business spends on discounts and rewards.
- How customer loyalty tiers perform over a selected date range.
- How gross profit compares with reward costs.

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Loyalty_Program_ROI_Dashboard.pbix`.
4. Connect to the dataset if Power BI requests the data source.
5. Refresh the data if necessary.
6. Use the Loyalty Tier and Purchase Date slicers to explore the dashboard.
